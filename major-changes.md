This page does not list detailed balance notes or new content introduced with each expansion such as Campaigns, Gear, Activities, etc. but instead focuses on changes or additions that have had a larger impact across the game.

Notable changes introduced during a Seasonal update that followed an expansion are grouped together with the rest of the expansion notes.

<h2 variant="justify"><img m="icon" src="/assets/images/icons/trait-new-light.png"> Destiny 2 <span part="suffix"><span style="opacity: 0.6;">v1.0.0 / </span>September 2017</span></h2>

- Initial game release

<h2 variant="justify"><img m="icon" src="/assets/images/icons/extra/expansion-forsaken.png"> Forsaken <span part="suffix"><span style="opacity: 0.6;">v2.0.0 / </span>September 2018</span></h2>

- <span class="fmt-label">New</span> **Collections** tab - keep track of all of the items and gear you have unlocked
- <span class="fmt-label">New</span> <a href="/manual/#triumphs-and-titles">Triumphs</a> tab
- <span class="fmt-label">New</span> **Game Mode**: <a href="/manual/#gambit">Gambit</a>
- <span class="fmt-label">New</span> **Gear**: Combat Bow weapon type
- <span class="fmt-label">New</span> **Gear**: Machine Gun weapon type
- <span class="fmt-label">New</span> **Subclasses**: Additional Super abilities for all Subclasses
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Gear**: Reintroduce Special weapons into Kinetic and Energy slots

[Full Patch Notes](https://www.bungie.net/en/Explore/Detail/News/47127)

<h2 variant="justify"><img m="icon" src="/assets/images/icons/expansion-shadowkeep.png"> Shadowkeep <span part="suffix"><span style="opacity: 0.6;">v2.6.0 / </span>October 2019</span></h2>

- <span class="fmt-label">New</span> **Seasonal <a href="/manual/#artifacts">Artifact</a> Slot**
- <span class="fmt-label">New</span> **Combat Systems**: <a href="/manual/#finishers">Finishers</a>
- <span class="fmt-label">New</span> **Gear**: Armor 2.0 with stat rework and fully customizable bonuses via Mods (existing armor _not_ updated)
- <span class="fmt-label">New</span> **<a href="/manual/#appearance-customization">Universal Ornaments</a>** - Cosmetic items to change the appearance of any Legendary Armor
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Gear**: Weapon Mods are now permanent unlocks and no longer consumable
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Gear**: Sword rework that adds energy for blocking/heavy attacks and revised stats
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Combat Systems**: Visual damage number crunch for better readability
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Controls**: Fully custom controller layouts

<h2 variant="justify"><img m="icon" src="/assets/images/icons/expansion-beyond-light.png"> Beyond Light <span part="suffix"><span style="opacity: 0.6;">v3.0.0 / </span>November 2020</span></h2>

- <span class="fmt-label">New</span> **Subclasses**: Stasis
- <span class="fmt-label">New</span> **Cross Play** - Enable matchmaking and friends list for Guardians across PC/Xbox/Playstation
- <span class="fmt-label">New</span> **<a href="/manual/#appearance-customization">Appearance Customization</a>** - New unified screen to apply Ornaments and Shaders to all armor at once, add ability to convert any owned armor into a Universal Ornament
- <span class="fmt-label">New</span> **New Light Tutorial** - Overhaul of player onboarding, including the return of the Cosmodrome
- <span class="fmt-label">New</span> **Monument to Lost Light** - Tower vendor that offers older Exotic Weapons
- <span class="fmt-label">New</span> **Destiny Timeline** - New section in the Director that lists all expansions and seasons in release order
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Progression**: Certain <a href="/manual/#triumphs-and-titles">Titles</a> now support Gilding by completing additional Triumphs
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Gear**: Shaders are now permanent unlocks and no longer consumable
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Gear**: Convert perks on Ghost Shells into <a href="/manual/#mods">Mods</a>
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Controls**: Add ADS Sensitivity Modifier for controller
- <span class="fmt-label" style="background-color: var(--m-color--accent-3);">Removed</span> **Destinations & Campaigns**: The Red War, Curse of Osiris, Warmind

<h2 variant="justify"><img m="icon" src="/assets/images/icons/expansion-witch-queen.png"> The Witch Queen <span part="suffix"><span style="opacity: 0.6;">v4.0.0 / </span>February 2022</span></h2>

- <span class="fmt-label">New</span> **<a href="/manual/#weapon-crafting">Weapon Crafting</a>**
- <span class="fmt-label">New</span> **Gear**: Glaive weapon type
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Subclasses**: Arc, Solar, and Void 3.0 rework with Aspects/Fragments, Subclass Verbs
- <span class="fmt-label" style="background-color: var(--m-color--accent-4);">Updated</span> **Controls**: Add full auto toggle option to make all weapons full auto
- <span class="fmt-label" style="background-color: var(--m-color--accent-3);">Removed</span> **Destinations & Campaigns**: Forsaken

<h2 variant="justify"><img m="icon" src="/assets/images/icons/extra/expansion-lightfall.png"> Lightfall <span part="suffix"><span style="opacity: 0.6;">v7.0.0 / </span>February 2023</span></h2>
