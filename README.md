# Guardian's Field Guide

![guardian's field guide logo](./assets/images/logo/glyph-gold.svg)

This is a companion instruction booklet for Destiny 2, aimed at new and returning players to get up to speed and fill in some of the gaps of the new player experience as the game has been through many transformations over the years.

## Project Background

This project is inspired by the little physical booklets that games used to include tucked into the front of the game box. Games don't really do that anymore, with some instead essentially building the manual into the game's UI. Destiny 2 does have a few really nice contextual help panels (for game mechanics) and the Timeline (for story overview), but I felt like it was missing some key details and really needed a comprehensive and concise manual.

As the name implies, this is meant to be a field guide that you can refer to here and there while you're playing, and I've tried to organize it to support that. Destiny 2 isn't the most complex game ever but especially starting out it can seem like a lot at once. Many things have been added and changed over the years too, which makes it nice to have a quick reference book.

## Goals

- Enable players to quickly get up to speed and playing the game, rather than going through lengthy guides
- Cover questions that I see very often from new and returning players
- Focus on core game knowledge rather than detailed guides for specific content
- Provide enough information to equip players to have a sense of progress, but preserve the fun that comes from discovering a new game.
